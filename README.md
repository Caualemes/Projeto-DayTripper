# Projeto DayTripper

Este projeto é um **protótipo** desenvolvido para uma apresentação (pitch) na disciplina de Design Thinking. O objetivo principal não era o site em si, mas sim a ideia de negócio por trás dele: uma plataforma para organizar e conectar pessoas em viagens de grupo para eventos.

---

## 💡 A Ideia: "Daytripper"

A plataforma "Daytripper" foi idealizada para simplificar a organização de viagens para eventos, como shows e jogos de futebol, em um formato de "bate-e-volta". A ideia é que os usuários possam encontrar e se juntar a grupos de viagem, ou criar os seus próprios, facilitando o transporte e a interação social.

---

## 🛠 Tecnologias Utilizadas

O protótipo foi construído usando tecnologias web básicas:

- **HTML:** Estrutura das páginas.
- **CSS:** Estilização e layout.
- **JavaScript:** Adiciona interatividade, como navegação entre páginas e a funcionalidade de login.
